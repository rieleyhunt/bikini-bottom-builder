Types in this room

Every type was tested in-game. Names with ? are best guesses at what the object does. Objects marked "home levels" didn't appear when placed in 1-1, so use them in the levels listed. Props picks the object's settings for this room; copy it from an existing object of the same type.

Tile palette

Pick a 16×16 tile. Right-click the level to pick one up. Tiles don't change collision; use Collision or Copy/Stamp for that.

Collision brush

Collision is an 8×8 grid of thin lines, not filled blocks: a floor is one row of Solid, a wall one column. Right-click erases. The yellow line usually sits a few pixels below the top of the ground art; SpongeBob's feet land on it. Every value was tested in-game; hover a brush for details.

Copy & stamp

Drag a box over a platform. Its tiles and collision are copied together, then switch to Stamp and click to place copies. This is the easiest way to build new platforms that you can stand on.
