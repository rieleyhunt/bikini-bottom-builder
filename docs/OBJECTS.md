# Object types

Every object type in BFBB (GBA, USA), identified by testing each one in mGBA (see [How it was made](HOW-IT-WAS-MADE.md#3-identifying-every-object)).

- **?** means the name is a best guess at what the object does.
- **In game** is how many times the type is used across all 112 rooms.
- **Home only** means the object didn't appear when placed in 1-1, because it needs graphics that only its own levels load.
