# Building from source

## Editor (HTML)

```sh
cd editor
npm install          # fonts embedded into the desktop build
python3 build.py
```

This writes three files:

- `dist/bikini-bottom-builder.html`: web version, loads fonts from Google Fonts
- `dist/BikiniBottomBuilder-local.html`: the same page as a complete HTML document, for opening from disk
- `desktop/index.html`: fonts embedded, used by the Windows app

The editor is plain JavaScript with no framework and no bundler:

| File | Contents |
|---|---|
| `core.js` | ROM reader and writer, LZ77 decompressor and compressor, column-RLE map codec, room loader, exporter, level names |
| `objinfo.js` | Object names, categories, test results and sprites. Generated by `tools/objid`. |
| `app.html` | UI, rendering, tools, undo and redo |

## Windows app

```sh
desktop/build.sh
```

Needs Go 1.22+, mingw-w64 (`x86_64-w64-mingw32-windres`), Python 3 and npm. It cross-compiles from Linux, macOS or WSL.

The app is a small Go server bound to `127.0.0.1` that serves the embedded editor and opens it in Edge or Chrome with `--app`, using its own profile. It shuts down when the window closes: the page pings `/ping` every 5 s and sends a beacon to `/bye` on close. Exports go through the browser's save picker, with a native Save dialog as a fallback. Logs are written to `%LocalAppData%\BikiniBottomBuilder\log.txt`.

## Research tools

```sh
export BFBB_ROM=/path/to/baserom.gba
cd tools
gcc -O2 -shared -fPIC -o libharness.so harness.c -lmgba    # needs libmgba-dev
python3 da.py 0x08024a98 40                                # disassemble (capstone)
```

| Tool | Purpose |
|---|---|
| `harness.c`, `emu.py` | Headless mGBA you can script from Python: run frames, press buttons, read and write memory, save states, screenshots, watchpoints, breakpoints |
| `da.py`, `xref.py` | Thumb disassembly and `BL` / literal cross-references |
| `lvl.py`, `render_lvl.py`, `loadroom.py` | Level decoding and rendering; boot straight into any room |
| `objid/` | The object identification pipeline, see its [README](../tools/objid/README.md) |
